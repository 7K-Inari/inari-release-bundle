Inari platform glue installed (CNPG PostgreSQL, Keycloak realm "inari").

Prerequisite (never installed by this chart): the CNPG operator and the
Keycloak operator (incl. CRDs) must already exist in the cluster — in the
GitOps layout they are separate ArgoCD Applications (see gitops/).

Exposure is Gateway API only: this chart never creates Ingress, Gateway or
GatewayClass resources. Enable keycloak.route and set gateway.name to point
the rendered HTTPRoute at a Gateway you have already deployed (a Gateway
controller must be installed in the cluster).
